# StreamBox - Netflix Inspired Streaming Platform

A responsive Netflix-inspired streaming platform built using React, Vite, Node.js, and Express.

This project demonstrates a complete frontend and backend login flow with mock authentication, movie browsing, movie details, and a personalized My List.

## Features

- Responsive Netflix-inspired login page
- Email and password authentication
- Frontend form validation
- Node.js and Express backend
- Mock/static user authentication
- Login API integration using Fetch
- Error handling for invalid credentials
- Dashboard after successful login
- Movie browsing and movie cards
- Movie images
- Movie details page
- Play/Watch page
- My List functionality
- Add and remove movies from My List
- Responsive design for desktop, tablet, and mobile
- Navigation using React Router

## Technologies Used

### Frontend
- React
- Vite
- React Router
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- CORS
